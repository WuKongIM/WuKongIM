## 本轮发现与修复

- 预挂载共享备份仓库使新节点数据根目录非空，被格式守卫误判成旧业务数据。仅允许唯一 `backup-repository` 目录/目录符号链接，仍拒绝任何未登记的 live database、未知文件或外部 Controller 状态；不读取或导入仓库内容。
- 新的 `stale read route`/admission busy 未映射到 SEND 重试错误，曾返回 HTTP 500。标量和批量权限读取统一映射到 `ErrRouteNotReady`，上下文取消/超时和损坏证据保留原错误。
- 三节点 Controller 写入转发已成功，本机镜像却还看不到刚取得的归档锁。真实恢复申请持续冲突；新增最小失败测试复现已完成写入被旧快照隐藏。备份状态适配器记录本身成功修改的可见版本下限，有界等待本机镜像追上，不新增 RPC；no-op 不等待不存在的增量版本。

新目录/错误映射/备份状态测试先失败后修复。相关 unit、integration、race、vet 和命名 FLOW 检查结果见本轮清单；本轮没有发布、购买云资源或发送 GitHub 评论。
