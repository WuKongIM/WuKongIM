All rows are proposed tests, not executed results. Existing report acceptance, counters, traffic and precedence remain the oracle. Each rejection must retain its old broad errors.Is sentinel where applicable, internally preserve the injected cause, expose only fixed diagnostics, and remain unable to synthesize a valid final report. Use a synthetic secret-bearing injected error to prove its text never appears in diagnostics, Error(), summary, JSON, or Markdown.
