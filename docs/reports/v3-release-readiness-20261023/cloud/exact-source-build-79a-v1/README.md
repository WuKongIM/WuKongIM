# Exact79a first construction

A fresh clean real-.git local clone at full79a was built with installed Go1.25.11 and no network, GOWORK=off, CGO0, trimpath and buildvcs=true. Both platforms embed the correct revision and clean source. No product or workload was run. This first build omitted the cloud workflow strip/buildid link flags, so its Linux binaries do not match the original cloud ELF bytes. That bounded comparison is retained as observed; the following exact-source-build-79a-cloud-flags-v1 layer supplies original flags and exact Linux byte equality. The native pair here is not selected for the next diagnostic. Source/rule hashes are complete for tracked Go files, AGENTS/FLOW and Go module files; cloud embedded assets are separately matched in the following layer. Ordinary content-addressed object cache reuse was allowed; no prebuilt executable was reused.
