## 时间对齐后的证据

双端各120个测量秒全部被采样边界覆盖，没有采样间断或过长采样，也没有计数回退。
客户端与探针使用同一单调时钟；服务端复用边界RPC建立偏移包络，宽度40.262–40.395毫秒，
其中包含事先声明的1000 ppm相对漂移余量。它是对齐误差范围，不是RPC时延。

CPU PSI有明显非零增量，但没有观测到同量级的严重RPC停顿。例如：

- 客户端第3窗样本18→19的CPU PSI `some` 增量404,296微秒，约1秒的采样区间可能与RPC秒7、8重叠；
  两秒分别95,305、95,113次调用，P99为0.279237、0.280067毫秒。
- 服务端第3窗样本89→90的CPU PSI增量356,873微秒，可能与RPC秒12、13重叠；
  两秒分别95,081、94,511次调用，P99为0.292887、0.291727毫秒。
- 全部测量重叠区间的steal增量均为0。PSI与steal是主机指标，不能直接断言RPC线程在等待，
  也不能凭steal为0排除调度干扰。
