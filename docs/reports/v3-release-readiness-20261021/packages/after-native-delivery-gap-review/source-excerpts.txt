1: # Offline object-storage planning
2: 
3: `plan-object-storage-publication.py` prepares a deterministic transport inventory

5: writes a new plan and prints a digest receipt. It does not connect to GitHub or a

11:   --inputs /path/to/reviewed-inputs.json \

16: the input JSON file. Repeating the same inputs with another output path produces
17: identical plan bytes, including when retained descriptors are reordered.

22: not authenticate who reviewed them. In particular, a matching self-reported

24: commit identity, or valid signatures. Run the existing provenance and
25: cryptographic verification separately; this plan never replaces those gates.

114: plan does not claim whole-site atomic switching, consistency of a client's
