`POST /channel/messagesync` 有界拉取一个 Channel 的已提交消息；实时收发仍由 SDK 与 Gateway 完成。

## 使用要点

- 当前样例把 `limit` 限制为 `1–100`；
- 分页时推进 sequence 游标，不要持续使用全零边界；
- 个人 Channel 的 `channel_id` 使用对端 UID；
- 在线 RECV 与同步结果可能重叠，优先按 `message_idstr` 去重；
- 空 `messages` 数组是合法结果。

<Callout type="warn" title="请求 UID 不是身份凭据">
  `login_uid` 只是字段。受信后端仍须验证调用方可代表该 UID 并读取对应 Channel。
</Callout>

若结果为空，先确认发送已获得成功 SENDACK，再检查方向、游标和成员可见性。`more=1` 时从本页最后一个 sequence 继续。
