---
title: Docker 部署
description: 一条命令启动带随机凭据和持久存储的 WuKongIM 单节点集群。
---

只需要 Docker 和 `curl`。下面的安装器会生成随机凭据、创建持久卷、启动最新 GitHub tag 对应的镜像，并等待节点就绪。

<Callout type="warn" title="默认用于本机快速体验">
  未指定版本时，安装器会在每次执行时查询 WuKongIM 仓库的最新 GitHub tag；指定旧版本时，其运行身份、基础镜像和健康检查能力以该版本为准。安装器不会自动配置域名、TLS、备份或多节点复制；承载生产流量前请完成[生产检查清单](/zh/server/deployment/production-checklist)。
</Callout>

## 1. 一键启动

```bash
curl -fsSL https://docs.githubim.com/install/docker.sh | sh
```

安装完成后，终端会显示 Manager 地址、用户名和随机密码。部署文件保存在当前目录的 `wukongim-docker/`，消息数据保存在 Docker Volume `wukongim-data`。

通过 `WK_VERSION` 安装指定版本，例如：

```bash
curl -fsSL https://docs.githubim.com/install/docker.sh | env WK_VERSION=3.0.0-beta.5 sh
```

版本必须存在对应的 GHCR 镜像。安装器会把所选镜像解析为不可变摘要后再启动；GitHub 查询失败、tag 无效或镜像不存在时会直接报错，不会退回旧版本。已有容器使用其他版本时，安装器会拒绝自动覆盖并保留数据卷；请先按照[升级与迁移](/zh/server/operations/upgrade-and-migration)确认兼容性，再删除旧容器并重新执行安装命令。

如果客户端从其他机器连接，在同一条命令中指定可访问的域名或 IP：

```bash
curl -fsSL https://docs.githubim.com/install/docker.sh | env WK_PUBLIC_HOST=im.example.com sh
```

两个选项可以同时使用：`env WK_VERSION=3.0.0-beta.5 WK_PUBLIC_HOST=im.example.com sh`。

## 2. 登录并验证

打开 [http://127.0.0.1:5301](http://127.0.0.1:5301)，使用安装器输出的 `admin` 和随机密码登录。确认节点状态：

```bash
curl --fail http://127.0.0.1:5001/readyz
```

然后按照[快速开始](/zh/guide/quick-start)连接两个测试用户，完成一次发送与接收。

<details>
<summary>服务器部署后，如何从自己电脑打开 Manager？</summary>

Manager 和 Product API 默认只监听服务器回环地址。建立 SSH 隧道后，在自己电脑打开相同的 Manager 地址：

```bash
ssh -N \
  -L 5001:127.0.0.1:5001 \
  -L 5301:127.0.0.1:5301 \
  user@server
```

</details>

<details>
<summary>常用运维命令</summary>

```bash
# 查看状态与日志
docker ps --filter name=wukongim
docker logs --follow --tail 100 wukongim

# 重启或停止
docker restart wukongim
docker stop wukongim

# 再次启动
docker start wukongim
```

凭据保存在 `wukongim-docker/.env`，权限为 `0600`。删除容器不会删除 `wukongim-data`；不要删除这个 Volume，除非确定不再需要其中的数据。

</details>

<details>
<summary>审查脚本后再执行</summary>

```bash
curl -fsSLO https://docs.githubim.com/install/docker.sh
less docker.sh
sh docker.sh
```

脚本固定镜像摘要，不使用 `latest`，也不会覆盖已有的部署环境文件。

</details>

<details>
<summary>彻底删除测试部署</summary>

先确认数据不再需要，再依次执行：

```bash
docker rm --force wukongim
docker volume rm wukongim-data
rm -r wukongim-docker
```

最后两条命令会永久删除消息数据和安装凭据。

</details>

生产部署还需要配置真实的 TCP/TLS 与 WSS 入口、限制 `5001` 和 `5301` 的访问、建立备份与回滚方案。需要复制和故障恢复时，继续阅读[多节点集群](/zh/server/deployment/multi-node)。
