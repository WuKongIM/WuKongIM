当前 Preview 软件源发布 `v3.0.0-beta.6`，仅支持 amd64/x86_64。已验证 Ubuntu 24.04、Debian 13、Rocky Linux 9 和 AlmaLinux 9；RHEL 9 可使用同一 EL9 软件源。

<Callout type="warn" title="Preview 是预发布通道">
  请先在非生产环境验证，再承载生产流量。
</Callout>

## 1. 安装

### Debian / Ubuntu

```bash
curl -fsSL https://packages.githubim.com/repo | sudo sh
sudo apt update
sudo apt install -y wukongim
```

### RHEL / Rocky / AlmaLinux 9

```bash
curl -fsSL https://packages.githubim.com/repo | sudo sh
sudo dnf -y --disablerepo='*' --enablerepo=wukongim-preview makecache --refresh
sudo dnf install -y wukongim
```

安装后检查版本：

```bash
wukongim version
```

软件包会创建服务账号、systemd 服务以及 `/etc/wukongim`、`/var/lib/wukongim` 和 `/var/log/wukongim`，但不会生成配置或启动服务。

## 2. 初始化配置

```bash
sudo wukongim init
```

保存只显示一次的管理员密码。根据实际环境检查节点 ID、持久化目录和外部地址，然后校验配置：

```bash
sudo wukongim config validate \
  --config /etc/wukongim/wukongim.toml
```

默认只监听回环地址。对外开放服务前，请先配置防火墙、TLS 和入口策略。

## 3. 启动并验证

```bash
sudo systemctl enable --now wukongim
curl --fail http://127.0.0.1:5001/readyz
```

`/readyz` 成功后再接入流量。启动失败时查看日志：

后台管理默认地址是 [http://127.0.0.1:5301](http://127.0.0.1:5301)，使用 `admin` 和初始化时保存的密码登录。如需公网访问，把配置文件 `[manager]` 中的 `listen_addr` 改为 `"0.0.0.0:5301"`，确认 `auth_on = true`，重启服务并在防火墙放行 TCP `5301`，然后打开 `http://<服务器公网IP>:5301`。更多说明见 [Manager 管理后台](/zh/server/operations/manager)。

```bash
sudo journalctl -u wukongim -n 100 --no-pager
```
