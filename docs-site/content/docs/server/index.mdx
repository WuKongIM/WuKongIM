服务端文档面向部署者、运维人员和需要理解系统内部结构的工程师。

<Callout type="warn" title="集群语义">
  每个部署都是集群。只有一个节点的部署称为单节点集群，不存在绕过集群行为的独立模式。
</Callout>

部署（包括 Kubernetes Beta）、配置、日常运维（包括升级与迁移）和服务端架构路径均已发布。页面发布不替代目标环境的部署、故障恢复或升级运行证据。
