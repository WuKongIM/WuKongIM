本页是 WuKongIM 公开启动配置的速查手册，并由启动配置 Schema 校验。每一行都说明字段用途、唯一环境变量映射，以及需要注意的默认、`0` 值、互斥、兼容或安全边界。

## 查阅方法

- 使用右侧目录按领域浏览，或用浏览器查找直接搜索 TOML 键、`WK_*` 环境变量或关键词。
- 日常配置优先写入 TOML；环境变量覆盖 TOML。未知 TOML 路径和未知 `WK_*` 变量会导致启动失败。
- `duration` 使用 Go 时长格式，如 `500ms`、`5s`、`24h`。`string_list` 和 `object_list` 的环境变量值必须是 JSON，并会替换完整列表。
- 配置在节点启动时加载；除非对应子系统明确说明，否则修改后需要重启节点。

<Callout type="info" title="默认值与配置基线">
  从 `v3.0.0-beta.7` 起，`wukongim init` 默认在 `/etc/wukongim/wukongim.toml` 生成面向安装场景的安全基线，并显式关闭 Diagnostics 和 Plugin。需要自定义位置时可使用 `wukongim init --config PATH`，原有的 `wukongim config init --config PATH` 兼容入口也继续保留。`wukongim.toml.example` 是可加载的开发与调优基线。这两个基线都不是完整的运行时默认值清单。下表中的“省略”指没有提供 TOML 和环境变量；它与显式的 `0`、空字符串或 `false` 可能具有不同含义。
</Callout>

`node.id`、`node.data_dir` 和 `cluster.listen_addr` 始终必填。种子加入还要求 `cluster.id`、非空的 `cluster.seeds`、可被其他节点访问的 `cluster.advertise_addr`，以及非空的 `cluster.join_token`。

如果要按部署任务定位字段，请先看[常用配置](/zh/server/configuration/common-configurations)；本页只负责逐字段查阅。

## 节点

| TOML | 环境变量 | 类型 | 说明 |
| --- | --- | --- | --- |
| `node.id` | `WK_NODE_ID` | `uint64` | 节点在集群中的稳定、非零唯一 ID；创建数据后不要更改。启动必填。 |
| `node.data_dir` | `WK_NODE_DATA_DIR` | `string` | 本节点持久化数据的根目录；应放在可写且受备份保护的磁盘上。启动必填。 |

## 集群

### 身份与发现

| TOML | 环境变量 | 类型 | 说明 |
| --- | --- | --- | --- |
| `cluster.listen_addr` | `WK_CLUSTER_LISTEN_ADDR` | `string` | 节点间 Cluster RPC 的监听地址；可绑定 `0.0.0.0`，但不能把通配地址提供给远端节点连接。启动必填。 |
| `cluster.id` | `WK_CLUSTER_ID` | `string` | Controller 使用的稳定集群标识；种子加入时必填。静态清单或隐式单节点集群省略时会按节点 ID 派生。 |
| `cluster.seeds` | `WK_CLUSTER_SEEDS` | `string_list` | 动态加入时用于发现集群的现有节点地址列表；不能为空，且不能与 `cluster.nodes` 同时使用。 |
| `cluster.advertise_addr` | `WK_CLUSTER_ADVERTISE_ADDR` | `string` | 动态加入时写入集群成员信息、供其他节点回连的稳定地址；使用 `cluster.seeds` 时必填。 |
| `cluster.join_token` | `WK_CLUSTER_JOIN_TOKEN` | `string` | 动态加入集群的共享认证令牌；字段一旦出现就不能为空，使用 `cluster.seeds` 时必填。启动快照与诊断均脱敏。 |
| `cluster.nodes` | `WK_CLUSTER_NODES` | `object_list` | 静态 Controller 投票节点列表，元素为 `{id, addr}`；非空列表必须包含当前 `node.id`，`id` 非零且唯一，`addr` 非空。不能与 `cluster.seeds` 同时使用；显式空列表（环境变量 JSON `null` 同样）当前会回退为隐式单节点集群，不能用来禁用集群。 |

### Slot Raft

| TOML | 环境变量 | 类型 | 说明 |
| --- | --- | --- | --- |
| `cluster.initial_slot_count` | `WK_CLUSTER_INITIAL_SLOT_COUNT` | `uint32` | 首次初始化时写入 Controller 持久状态的独立 Slot Raft Group 数，不得大于 `cluster.hash_slot_count`；省略或为 `0` 时使用 `1`。已有集群以持久值为准，修改不会调整 Slot 数，调大还可能阻塞节点就绪；初始化后不要更改。 |
| `cluster.hash_slot_count` | `WK_CLUSTER_HASH_SLOT_COUNT` | `uint16` | 把路由键分配到 Slot Raft Group 的稳定 Hash Slot 分区数；省略或为 `0` 时使用 `256`，集群初始化后不要更改。 |
| `cluster.slot_replica_n` | `WK_CLUSTER_SLOT_REPLICA_N` | `uint16` | 初始化 Controller 状态时每个 Slot Raft Group 的投票副本数；已有集群以 Controller 持久状态为准。`0` 在静态拓扑按投票节点数推导，种子加入时回退为 `1`；静态显式值不得超过投票节点数。 |
| `cluster.channel_replica_n` | `WK_CLUSTER_CHANNEL_REPLICA_N` | `uint16` | 新建频道的期望数据副本数；`0` 跟随本地有效的 `cluster.slot_replica_n`，种子加入时也会成为 `1`，不会读取已有 Controller 的持久副本数。多副本集群应在所有节点显式配置一致值，并与可用节点和故障域匹配。 |
| `cluster.slot_tick_interval` | `WK_CLUSTER_SLOT_TICK_INTERVAL` | `duration` | Slot Raft 本地 Tick 的时间间隔；默认 `50ms`，必须大于 `0`。 |
| `cluster.slot_election_tick` | `WK_CLUSTER_SLOT_ELECTION_TICK` | `int` | 触发 Slot Raft 选举前等待的 Tick 数；默认 `40`，必须大于心跳 Tick。 |
| `cluster.slot_heartbeat_tick` | `WK_CLUSTER_SLOT_HEARTBEAT_TICK` | `int` | Slot Raft 发送心跳的 Tick 间隔；默认 `2`，必须大于 `0`。 |
| `cluster.slot_log_compaction_enabled` | `WK_CLUSTER_SLOT_LOG_COMPACTION_ENABLED` | `bool` | 是否启用本地 Slot Raft 快照与日志压缩；省略时启用。 |
| `cluster.slot_log_compaction_trigger_entries` | `WK_CLUSTER_SLOT_LOG_COMPACTION_TRIGGER_ENTRIES` | `uint64` | 相对上次快照新增多少条已应用日志后允许再次压缩；默认 `10000`，必须大于 `0`。 |
| `cluster.slot_log_compaction_check_interval` | `WK_CLUSTER_SLOT_LOG_COMPACTION_CHECK_INTERVAL` | `duration` | 检查 Slot Raft 日志是否需要压缩的最小间隔；默认 `30s`，必须大于 `0`。 |

### Channel Runtime

| TOML | 环境变量 | 类型 | 说明 |
| --- | --- | --- | --- |
| `cluster.channel_reactor_count` | `WK_CLUSTER_CHANNEL_REACTOR_COUNT` | `int` | 本节点的 Channel Reactor 分区数；`0` 使用 CPU 感知的运行时默认值。 |
| `cluster.channel_store_append_workers` | `WK_CLUSTER_CHANNEL_STORE_APPEND_WORKERS` | `int` | 阻塞式 Leader 存储追加的最大 Worker 数；`0` 使用 Channel 运行时默认值。 |
| `cluster.channel_store_append_batch_max_wait` | `WK_CLUSTER_CHANNEL_STORE_APPEND_BATCH_MAX_WAIT` | `duration` | 跨频道合并 Leader 存储追加任务的最长等待时间；`0` 使用 Channel Worker 默认值。 |
| `cluster.channel_store_apply_workers` | `WK_CLUSTER_CHANNEL_STORE_APPLY_WORKERS` | `int` | 阻塞式 Follower 存储应用的最大 Worker 数；`0` 使用 Channel 运行时默认值。 |
| `cluster.channel_rpc_workers` | `WK_CLUSTER_CHANNEL_RPC_WORKERS` | `int` | 阻塞式 Channel 复制 RPC 的最大 Worker 数；`0` 使用默认值 `96`。 |
| `cluster.channel_rpc_batch_max_items` | `WK_CLUSTER_CHANNEL_RPC_BATCH_MAX_ITEMS` | `int` | 一次发往同一目标的 Pull 或 PullHint RPC 最多合并项数；`0` 使用默认值 `8`。 |
| `cluster.max_channels` | `WK_CLUSTER_MAX_CHANNELS` | `int` | 本节点可同时加载的 Channel Runtime 上限；`0` 表示不设置上限。 |
| `cluster.channel_append_batch_max_records` | `WK_CLUSTER_CHANNEL_APPEND_BATCH_MAX_RECORDS` | `int` | 排队记录数达到该值时触发 Channel 存储追加；`0` 使用运行时默认值。 |
| `cluster.channel_append_batch_max_wait` | `WK_CLUSTER_CHANNEL_APPEND_BATCH_MAX_WAIT` | `duration` | 最早一条排队 Channel 追加在刷盘前可等待的最长时间；`0` 使用运行时默认值。 |
| `cluster.channel_append_batch_adaptive_flush` | `WK_CLUSTER_CHANNEL_APPEND_BATCH_ADAPTIVE_FLUSH` | `bool` | 是否让低流量频道使用更短的自适应刷盘等待；省略时关闭。 |
| `cluster.channel_append_batch_cold_max_wait` | `WK_CLUSTER_CHANNEL_APPEND_BATCH_COLD_MAX_WAIT` | `duration` | 启用自适应刷盘后，低流量频道的最长等待时间；`0` 沿用普通批处理窗口。 |
| `cluster.channel_follower_recovery_probe_interval` | `WK_CLUSTER_CHANNEL_FOLLOWER_RECOVERY_PROBE_INTERVAL` | `duration` | 暂停的 Follower 恢复探测基础间隔；`0` 使用 Channel 运行时默认值。 |
| `cluster.channel_follower_recovery_probe_jitter` | `WK_CLUSTER_CHANNEL_FOLLOWER_RECOVERY_PROBE_JITTER` | `duration` | Follower 恢复探测的随机抖动窗口，用于分散集中探测；`0` 使用运行时默认值。 |

### 健康与持久提交

| TOML | 环境变量 | 类型 | 说明 |
| --- | --- | --- | --- |
| `cluster.node_health_report_interval` | `WK_CLUSTER_NODE_HEALTH_REPORT_INTERVAL` | `duration` | 本节点向 Controller 上报精简健康信息的间隔；默认 `5s`，必须大于 `0`。 |
| `cluster.node_health_report_ttl` | `WK_CLUSTER_NODE_HEALTH_REPORT_TTL` | `duration` | Controller 信任最近一次节点健康报告的时长；默认 `30s`，不得小于上报间隔。 |
| `cluster.commit_coordinator_sync` | `WK_CLUSTER_COMMIT_COORDINATOR_SYNC` | `bool` | 持久提交同步兼容开关；省略等效于 `true`，显式值也只能为 `true`，WuKongIM 不允许关闭持久同步。 |
| `cluster.commit_coordinator_flush_window` | `WK_CLUSTER_COMMIT_COORDINATOR_FLUSH_WINDOW` | `duration` | 合并相邻 Channel 持久提交请求的最长等待时间；默认 `500us`，显式值必须大于 `0`。 |
| `cluster.commit_coordinator_max_requests` | `WK_CLUSTER_COMMIT_COORDINATOR_MAX_REQUESTS` | `int` | 一次物理提交可合并的逻辑请求上限；`0` 表示不按请求数限制。 |
| `cluster.commit_coordinator_max_records` | `WK_CLUSTER_COMMIT_COORDINATOR_MAX_RECORDS` | `int` | 一次物理提交可合并的消息记录上限；`0` 表示不按记录数限制。 |
| `cluster.commit_coordinator_max_bytes` | `WK_CLUSTER_COMMIT_COORDINATOR_MAX_BYTES` | `int` | 一次物理提交可合并的近似负载字节上限；`0` 表示不按字节数限制。 |
| `cluster.commit_coordinator_shards` | `WK_CLUSTER_COMMIT_COORDINATOR_SHARDS` | `int` | 消息数据库独立提交协调器数量；`0` 使用 `1`，增加前应针对存储进行压测。 |

## 频道迁移

| TOML | 环境变量 | 类型 | 说明 |
| --- | --- | --- | --- |
| `channel_migration.enable` | `WK_CHANNEL_MIGRATION_ENABLE` | `bool` | 是否启动推进 Channel 迁移和创建修复任务的后台 Worker；省略时启用。 |
| `channel_migration.scan_interval` | `WK_CHANNEL_MIGRATION_SCAN_INTERVAL` | `duration` | 扫描并推进 Channel 迁移工作的时间间隔；省略时使用 `1s`，显式值必须大于 `0`。 |

| `api.external_wss_addr` | `WK_EXTERNAL_WSSADDR` | `string` | 向容量发现等调用方公布的安全 WebSocket URL 覆盖项；留空时从首个匹配的 `gateway.listeners` 推导，无匹配项则为空。它不会创建监听器，诊断制品会脱敏。 |
