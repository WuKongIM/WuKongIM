title: Configuration Reference

This page is checked against the public startup configuration schema. It lists every accepted TOML path and its one canonical environment mapping. Environment values override TOML; unknown TOML paths and unknown `WK_*` variables fail startup.

<Callout type="info" title="Values and defaults">
  `wukongim.toml.example` is a loadable development baseline, not a runtime-default catalog for every field. Some omitted or zero values are derived from hardware, topology, or internal defaults. The Manager startup snapshot resolves a bounded set of critical fields; confirm others through subsystem runtime state, metrics, and pre-production load tests.
</Callout>

`node.id`, `node.data_dir`, and `cluster.listen_addr` are always required. Seed joining additionally requires `cluster.advertise_addr` and a non-empty `cluster.join_token`. List environment values are JSON and replace the complete list.

Kinds: `string`, `bool`, integer `int`/`uint*`, `float`, Go-format `duration`, and `string_list`/`object_list` for lists of strings or objects.
