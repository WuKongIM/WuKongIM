Server documentation is for deployers, operators, and engineers who need to understand the system internals.

<Callout type="warn" title="Cluster semantics">
  Every deployment is a cluster. A deployment with one node is a single-node cluster; there is no standalone path that bypasses cluster behavior.
</Callout>

Start a new environment from Deployment; use Configuration, Operations, and Architecture as server references when needed. Publication does not replace deployment, recovery, or upgrade execution evidence for the target environment.
