This area now publishes executable contracts for application integration developers. Phase 12 promises only the Product HTTP subset required by the golden sample, its shared conventions, compatibility snapshot, error handling, and complete Reason Code enum.

## Goal and completion criteria

A developer should create a development identity, discover Gateway ingress, recover offline messages from a trusted backend, and handle HTTP and protocol outcomes precisely without promoting other source routes to public API.

<Callout type="warn" title="Not the complete v3 API">
  This is a Beta golden-path subset. The repository's older OpenAPI still contains v2 material. Complete OpenAPI, client protocols, webhooks, operations APIs, and other domain references remain planned.
</Callout>

## Compatibility target

Server revision, SDK, Node.js, Chromium, and contract summary appear on [API Compatibility](/en/api/compatibility) and in `/compatibility.json`. URLs remain unversioned, but a snapshot does not promise compatibility with every revision.

## Prerequisites

- Product HTTP is open only to the localhost BFF or a trusted product backend;
- the default Gateway stored-token gap is explicitly accepted as a local-development limitation;
- the single-node cluster passes `/readyz`;
- the caller parses each compatible endpoint response separately.

## Expected result

The golden BFF is the browser-side boundary for all three HTTP entries; realtime messages use the SDK; error classification preserves HTTP separately from CONNACK/SENDACK; Reason Code remains automatically aligned with the Go enum.

## Troubleshooting

- **A required endpoint is absent from Product HTTP subset:** it remains unpublished; do not infer support from old OpenAPI or source location.
- **The browser calls the server directly:** replace it with a same-origin BFF call and tighten the network.
- **Fields disagree with the docs:** fail shared-contract validation and repair runtime, sample, and bilingual pages together.

## Security and responsibility boundary

Product HTTP has no general business-authentication middleware and the default Gateway has no stored-token CONNECT validation. Phase 12 does not describe its local development loop as a production security solution.
