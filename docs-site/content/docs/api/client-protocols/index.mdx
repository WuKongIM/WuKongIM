客户端通过 Gateway 的 TCP 或 WebSocket Listener 建立长连接。WKProto 公共基线包含连接协商、发送、接收确认和心跳。MQTT 使用独立的 MQTT 5 TCP 入口，共用 IM 用户、频道和消息。

<Callout type="info" title="协议不是 HTTP API">
  TCP 二进制帧和 WebSocket 消息不属于 OpenAPI。这里记录 Wire 与 Gateway 行为，不虚构 HTTP 路径。
</Callout>

## 当前边界

- 公共核心包含 CONNECT/CONNACK、SEND/SENDACK、RECV/RECVACK、PING/PONG 与服务端出站 stream.* EVENT。
- WKProto 的 `DISCONNECT`、`SUB`、`SUBACK` 目前只是 codec 合同，不代表产品 Gateway 已发布对应入口。
- 服务端可通过 `EVENT` 投递公开流式消息事件；任意客户端 EVENT 入站仍不支持，入站只接受 benchmark terminal-fence 工具请求。
- WebSocket 可承载 WKProto bytes；JSON-RPC bridge 支持固定 EasySDK 的核心在线路径，其余方法仍按矩阵标为实验性或缺失。

数值含义见 [公共数据字典](/zh/api/dictionaries)，生产信任边界见[认证与安全](/zh/api/authentication)。
