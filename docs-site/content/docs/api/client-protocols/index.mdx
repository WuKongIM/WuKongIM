客户端通过 Gateway 的 TCP 或 WebSocket Listener 建立长连接。当前公共基线是同一组 WKProto 语义：连接协商、发送、接收确认和心跳。

<Callout type="info" title="协议不是 HTTP API">
  TCP 二进制帧和 WebSocket 消息不属于 OpenAPI。这里记录 Wire 与 Gateway 行为，不虚构 HTTP 路径。
</Callout>

## 当前边界

- 公共核心只包含 CONNECT/CONNACK、SEND/SENDACK、RECV/RECVACK 和 PING/PONG。
- `DISCONNECT`、`SUB`、`SUBACK` 目前只是 codec 合同，不代表产品 Gateway 已发布对应入口。
- `EVENT` 保留给受控内部协议，不是应用事件 API。
- WebSocket JSON-RPC、精确二进制布局和加密细节仍在校准，不能从本页推断方法或安全保证。

数值含义见 [公共数据字典](/zh/api/dictionaries)，生产信任边界见[认证与安全](/zh/api/authentication)。
