| 格式 | 适用范围 | 不适用范围 |
| --- | --- | --- |
| OpenAPI 3.1 | HTTP 请求、响应和 Webhook 回调 | WKProto、MCP、Node transport、Unix-socket RPC |
| JSON Schema 2020-12 | 实验性 JSON-RPC codec 数据形状 | 产品支持或兼容性承诺 |
| 协议页面 | 二进制布局、协商、稳定性与信任边界 | HTTP SDK 自动生成 |

业务后端从完整 Product HTTP 合同开始；只实现一个受限场景时，可选择窄 Profile。客户端实时连接必须使用 [WKProto](/zh/api/client-protocols/tcp-binary)。
