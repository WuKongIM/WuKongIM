| 格式 | 适用范围 | 不适用范围 |
| --- | --- | --- |
| OpenAPI 3.1 | HTTP 请求、响应和 Webhook 回调 | WKProto、MCP、Node transport、Unix-socket RPC |
| JSON Schema 2020-12 | 固定 EasySDK 核心路径与其余实验性 JSON-RPC 数据形状 | 通用 JSON-RPC 或平台运行兼容承诺 |
| 协议页面 | 二进制布局、协商、稳定性与信任边界 | HTTP SDK 自动生成 |

业务后端从完整 Product HTTP 合同开始；只实现一个受限场景时，可选择窄 Profile。完整 SDK 实时连接使用 [WKProto](/zh/api/client-protocols/tcp-binary)；四个固定 EasySDK 的轻量在线路径可使用受支持的 [WebSocket JSON-RPC 核心合同](/zh/api/client-protocols/json-rpc)。
