## 目标与完成标准

本页区分两种证据：同一构建 tuple 中三个 Product HTTP 入口的黄金场景 receipt，以及 16 个 Channel/Conversation 管理入口的当前源码校准。只有匹配的成功 receipt 才能证明黄金样例覆盖其精确三入口 tuple；它不证明管理合同，也不代表仓库全部 HTTP 路由或正式 v3 稳定性承诺。

## 前置条件

- 已区分旧完整 OpenAPI 与 Phase 12 切片级合同；
- 已区分三入口黄金合同与 16 入口管理合同的证据范围；
- 能读取当前构建 revision 和验证证明；
- Product HTTP 只允许受信后端访问；
- 合同、BFF、文档或运行时任何一处变化都会重新运行黄金场景。

## 发布范围

| 入口 | Phase 12 状态 | 场景证据目标 |
| --- | --- | --- |
| `POST /user/token` | 黄金路径子集 | BFF 合同测试 + 真实身份创建 |
| `GET /route` | 黄金路径子集 | BFF 合同测试 + 真实 WebSocket 发现 |
| `POST /channel/messagesync` | 黄金路径子集 | BFF 合同测试 + Bob 重连离线恢复 |

管理合同另发布 10 个 Channel 变更和 6 个 canonical Conversation 操作。它们具有源码与入口测试校准，但状态是“未纳入黄金场景证明”，不能读取上方 `verified` 值作为运行时 smoke 证据。精确范围见[频道](/zh/api/product-http/channels)与[会话](/zh/api/product-http/conversations)。

消息实时发送通过 JavaScript SDK 与 Gateway 完成，不把 `/message/send` 加入任一 HTTP 子集。其他未列出的 Product HTTP、运维 API、Webhook、TCP 细节、JSON-RPC Schema 和完整 OpenAPI 仍处于规划状态。

## URL 与版本策略

当前路径保持 `/{lang}/api/...`，不迁移到 `/v3/`。版本身份记录在构建 revision 和兼容清单中：

- “v3 Beta snapshot” 是可复现源码组合，不是正式语义化版本；
- URL 不变不表示任意源码 revision 都兼容；
- 更新服务端、SDK 或合同后，必须重新执行真实黄金场景；
- 未通过该场景的组合只能标为未验证。

## 预期结果

使用同一黄金快照时，BFF 能创建开发身份、发现 WebSocket 地址，并在 Bob 重连时恢复已提交消息。管理合同变化同样会触发文档集成校验，但只有专门的后续场景证据才能为其提供 runtime receipt。

## 失败诊断

- **端点字段与页面不同**：以共享合同校验失败处理，不能人工让 BFF 和文档各自兼容一套。
- **HTTP 子集通过、SDK 发送失败**：继续检查 SDK/协议兼容性；HTTP 成功不能外推 Gateway 行为。
- **源码 revision 不在快照中**：将结果标记为未验证，并运行完整 smoke test。
- **旧 OpenAPI 与本页冲突**：旧文件不属于本阶段权威；不要用它扩大已发布承诺。
- **管理页面已发布但 `verified=false`**：该字段只描述黄金三入口 tuple；用源码校准门禁判断管理合同是否对齐。

## 安全与责任边界

API 兼容不等于 API 可直接公网暴露。默认 Product HTTP 缺少通用业务鉴权，默认 Gateway 缺少 stored-token CONNECT 校验；兼容测试不会替代这些生产控制。
