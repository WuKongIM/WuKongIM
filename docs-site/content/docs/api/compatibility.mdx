API 页面描述当前构建对应的合同。URL 不变不代表不同服务端、SDK 或合同版本自动兼容。

## 当前快照

<CompatibilitySnapshot locale="zh" />

快照中的验证状态只覆盖以下基础接入流程：

| 接口 | 验证内容 |
| --- | --- |
| `POST /user/token` | 创建开发身份 |
| `GET /route` | 发现 WebSocket 入口 |
| `POST /channel/messagesync` | 重连后恢复已提交消息 |

Channel 与 Conversation 管理接口另有 OpenAPI 合同和合同校验，但不包含在上方端到端验证状态中。

## 版本规则

- 升级服务端、SDK 或合同后，应重新验证应用接入流程。
- 未验证的组合应视为未知兼容性，而不是默认兼容。
- 只使用当前页面与 OpenAPI 合同列出的字段和接口。

兼容不等于可直接公网暴露。Product HTTP 仍须放在受信网络或已鉴权代理之后。接口范围见 [Product HTTP API](/zh/api/product-http)。
