## 版本规则

- 升级服务端、SDK 或合同后，应重新验证应用接入流程。
- 未验证的组合应视为未知兼容性，而不是默认兼容。
- 以完整合同判断当前源码 Surface，以窄 Profile 判断特定接入的采用范围。

兼容不等于可直接公网暴露。Product HTTP 仍须放在受信网络或已鉴权代理之后；私有与实验性接口见[接口清单](/zh/api/interface-inventory)。
