## 使用边界

- Product HTTP 仅供受信后端调用，不应直接暴露给浏览器或移动端。
- HTTP 状态、端点响应与 CONNACK/SENDACK Reason Code 属于不同层，需分别处理。
- 版本和验证范围见 [API 兼容性](/zh/api/compatibility)，错误处理见 [错误响应](/zh/api/product-http/errors)。
