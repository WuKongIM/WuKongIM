运维 HTTP 与 Product HTTP 共用 API 监听器，但面向运维系统，不是业务集成 API。

[下载 Operations HTTP OpenAPI 3.1](/contracts/operations-http.openapi.json)

| Method | Path | 条件 | 稳定性 |
| --- | --- | --- | --- |
| `GET` | `/healthz` | 始终注册 | 稳定 |
| `GET` | `/readyz` | 始终注册 | 稳定 |
| `ANY` | `/metrics` | 配置 Prometheus Handler 后注册 | 稳定的 Prometheus 暴露格式 |
| `GET` | `/top/v1/snapshot` | 始终注册；无 Provider 时返回 404 | 不稳定 |

<Callout type="error" title="监听器没有运维认证">
  这四个入口没有内建认证。仅向受控网络暴露，并在反向代理、Service Mesh 或防火墙处添加 TLS、访问控制和限流。
</Callout>
