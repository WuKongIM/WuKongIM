title: Webhook

---

Webhook 把已提交消息、离线候选接收者和在线状态变化 POST 到一个业务端点。它是服务端出站协议，不是客户端收件箱，也不属于 Product HTTP 的入站 `paths`。

[下载 OpenAPI 3.1 Webhook 合同](/contracts/webhooks.openapi.json)

## 请求

```text
POST {http_addr}?event={event_name}
Content-Type: application/json
```

已有查询参数会保留，并覆盖或追加 `event`。事件名只出现在 Query 中；请求体**没有通用信封**，结构由事件决定。当前仅支持：

| 事件 | 顶层 JSON |
| --- | --- |
| `msg.notify` | 已提交消息数组 |
| `msg.offline` | 一条消息与离线 UID 的扁平对象 |
| `user.onlinestatus` | 兼容状态字符串数组 |

## 配置

`http_addr` 非空即启用 Webhook；`focus_events=[]` 表示投递全部三个事件。

```toml
[webhook]
http_addr = "https://events.example.com/wukongim"
focus_events = ["msg.notify", "msg.offline", "user.onlinestatus"]
queue_size = 1024
workers = 16
msg_notify_batch_max_items = 100
msg_notify_batch_max_wait = "500ms"
online_status_batch_max_items = 512
online_status_batch_max_wait = "2s"
offline_uid_batch_size = 512
request_timeout = "5s"
retry_max_attempts = 3
```
