Product HTTP 提供基础接入与受信管理接口。完整 OpenAPI 与当前 `internal/access/api` 注册的 41 条操作一一对应。
进入具体接口页可查看每个查询参数和 JSON 字段的类型、必填性、默认值、范围以及运行时兼容行为。

OpenAPI：[完整合同](/contracts/product-http.openapi.json) · 窄 Profile：[基础接入](/contracts/javascript-web-quickstart.openapi.json) · [消息发送](/contracts/product-http-messaging.openapi.json) · [Channel 与 Conversation](/contracts/product-http-management.openapi.json)

</Callout>
