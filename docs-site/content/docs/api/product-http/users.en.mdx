`POST /user/token` stores device-token metadata for a UID from a trusted backend.

## Key points

- Generate the token on the server; never accept one asserted by the browser.
- `device_flag` identifies the device category; `device_level` controls same-category Session policy.
- `200` confirms only that the metadata write succeeded.

<Callout type="error" title="CONNECT authentication is separate">
  The default Gateway does not validate later CONNECT packets against this stored token. Production must configure explicit token validation.
</Callout>
