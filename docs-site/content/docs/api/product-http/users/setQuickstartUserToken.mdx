          创建或更新设备 Token

          创建缺失的 UID 元数据并更新一个设备 Token；Gateway Token 鉴权默认启用，后续相同 UID 与设备类别的
          CONNECT 凭据必须与它匹配。

          UpdateTokenRequest

          设备 Token 更新参数。

          additionalProperties true

          uid `string` minLength: 1 要创建或更新设备 Token 的用户 ID；不得包含 @、# 或 &。

          token `string` minLength: 1 与该用户和设备类别一起持久化的不透明 Token；默认 Gateway 要求后续
          CONNECT 凭据与它完全匹配。

          device_flag `integer:uint8` 0–255; default: `0`
          设备类别；0=APP、1=Web、2=PC、99=系统设备，省略时为 0。

          device_level `integer:uint8` 0–255; default: `0`
          同类设备冲突级别；0=Slave、1=Master，省略时为 0。

          200 Mutation accepted

          StatusEnvelope

          旧式变更成功响应。

          additionalProperties false

          status `integer` const: `200` 固定为 200 的应用层状态。

          400 Input, validation, dependency, or downstream error

          CompatibilityError

          多个旧式入口共用的 HTTP 400 错误体。

          msg `string` — 供人阅读且不保证稳定的错误文本；不要据此做机器分支。

          status `integer` const: `400` 固定为 400 的应用层状态。

          503 Controller restore maintenance is active

          MaintenanceError

          集群处于恢复维护期间的 503 错误体。

          error `string` const: `"maintenance"` 稳定的 maintenance 错误类别。

          message `string` const: `"restore maintenance is active"` 当前恢复维护说明。

- **调用方**：仅限受信业务后端
- **作用域**：Token 持久化到集群；Master 设备的旧连接由请求处理节点在约 10 秒后发起关闭。
- **成功判定**：200 表示 Token 写入已完成，不表示旧连接已经关闭。
