          match it.

          UpdateTokenRequest

          Device-token update parameters.

          additionalProperties true

          uid `string` minLength: 1 User ID whose device token is created or
          updated; it must not contain @, #, or &.

          token `string` minLength: 1 Opaque token persisted for this user and
          device category; the default Gateway requires later CONNECT
          credentials to match it exactly.

          device_flag `integer:uint8` 0–255; default: `0` Device category;
          0=APP, 1=Web, 2=PC, and 99=system, defaulting to 0 when omitted.

<Callout type="warn" title="Operation boundary">

- **Caller**: Trusted backend only
- **Scope**: The token is persisted cluster-wide; for a Master device, the handling node starts closing old sessions after about 10 seconds.
- **Success**: A 200 response means the token write completed, not that old sessions are already closed.
