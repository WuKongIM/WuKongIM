<Callout type="warn" title="接口边界">

- **调用方**：仅限受信业务后端
- **作用域**：Channel 元数据与成员写入集群存储；large 会在成员变更后按当前成员数重新计算。
- **原子性**：元数据、清空旧成员、分批加入成员和刷新 large 是多个阶段，不构成事务。
- **恢复**：超时或 400/5xx 后按业务期望状态重放，并通过受保护的 Manager 查询核对成员。

</Callout>
