<Callout type="warn" title="接口边界">

- **调用方**：仅限受信业务后端
- **作用域**：派生允许列表可在父 Channel 创建前写入，并在父 Channel 出现后生效。channel_type=1 时，channel_id 是白名单所属用户的 UID。个人 UID 不得含 @。群白名单只修改权限。
- **成功判定**：个人白名单写入后，每个不同的对方 UID 只准备一次双方的成员关系，且只刷新白名单所属用户的 activated_at。重复添加会刷新激活时间。保留加入、已读和历史隐藏边界，空会话显示规则保持不变。
- **恢复**：目录准备或激活失败时，前序写入可能已提交。重试相同请求可完成剩余步骤。

</Callout>
