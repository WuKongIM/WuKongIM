`GET /route` 返回已配置的客户端 Gateway 地址。

## 使用要点

- HTTPS 页面优先使用非空 `wss_addr`，否则使用 `ws_addr`；
- 浏览器样例不使用 `tcp_addr`；
- 断线后重新发现地址，不要永久缓存旧结果。

<Callout type="warn" title="地址发现不是鉴权">
  `/route` 成功不代表 UID 已授权，也不代表 CONNECT 成功。
</Callout>

地址为空时检查 Gateway 外部地址配置；地址可达但连接失败时检查协议版本和 CONNACK Reason Code。
