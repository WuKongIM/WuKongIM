`POST /user/token` 由受信后端保存 UID 的设备 Token 元数据。

## 使用要点

- Token 应由服务端生成，不要由浏览器自报；
- `device_flag` 表示设备类别，`device_level` 决定同类设备会话策略；
- `200` 只表示元数据写入成功。

<Callout type="error" title="不会自动启用 CONNECT 鉴权">
  默认 Gateway 不会用这里保存的 Token 校验后续 CONNECT。生产环境必须配置独立的 Token 校验。
</Callout>

调用失败时先检查必填字段；连接失败时分别检查 `/route`、Gateway 和 CONNACK。更多安全要求见[认证与安全](/zh/api/authentication)。
