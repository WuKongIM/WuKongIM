## Key points

- Integer flags are true only when their value is `1`.
- `reset=1` replaces the durable-subscriber snapshot; bound request size for large groups.
- Durable subscribers and `/tmpchannel/subscriber_set` temporary members are separate.
- Person Channels (Type 1) do not support ordinary subscriber management.
- Route names retain `blacklist` / `whitelist`; they mean denylist / allowlist.

## Current scope

The 10 operations above are in the current contract. These existing routes remain unpublished:

- `POST /channel/info`
- `POST /channel/delete`
- `POST /channel/subscriber_remove`
- `POST /channel/blacklist_set`
- `POST /channel/whitelist_set`

Routes absent from the contract are outside the current public scope. See [Error Responses](/en/api/product-http/errors) for shared failures.
