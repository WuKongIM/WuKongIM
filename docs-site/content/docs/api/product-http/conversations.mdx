## 列表同步

1. 首次调用 `/conversation/list` 时使用空 `cursor`；
2. 应用 `conversations`，删除 `deletes`，把 `unresolved` 交给 `/conversation/retry`；
3. `done=false` 时原样回传 `next_cursor`，即使本页为空；
4. 仅在 `done=true` 后保存 `coverage`；
5. `reset_required=true` 时清空本地会话投影并重新同步。

## 使用要点

- `read_seq` 是单调未读下界，不是消息游标或已读回执；
- `setUnread` 只能减少未读数；
- `delete` 只隐藏当前投影，不删除 Channel 或成员关系；
- `message_idstr` 可避免 JavaScript 大整数精度损失。

旧 `POST /conversation/sync` 不在当前合同内；新接入使用 `/conversation/list` 与 `/conversation/retry`。通用错误处理见[错误响应](/zh/api/product-http/errors)。
