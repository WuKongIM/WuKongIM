## 使用要点

- 整数标志只有值为 `1` 时表示 true；
- `reset=1` 会替换持久订阅者快照；大型群组应限制单次请求大小；
- 持久订阅者与 `/tmpchannel/subscriber_set` 的临时成员相互独立；
- 个人 Channel（Type 1）不支持普通订阅者管理；
- 路由沿用 `blacklist` / `whitelist` 命名，分别表示 denylist / allowlist。

## 当前范围

上方 OpenAPI 列出的 10 个操作属于当前合同。以下现存路由暂不发布：

- `POST /channel/info`
- `POST /channel/delete`

- `POST /channel/whitelist_set`

未出现在合同中的路由不属于当前公开范围。通用错误处理见[错误响应](/zh/api/product-http/errors)。
