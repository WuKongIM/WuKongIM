<Callout type="warn" title="接口边界">

- **调用方**：仅限受信业务后端
- **作用域**：业务后端负责修改权限和时间窗口；不改变消息 ID、序号、原发送时间、未读或排序。
- **成功判定**：200 表示修改及幂等结果已由 Slot 多数派提交并应用，不等待终端接收。
- **恢复**：结果不确定时使用完全相同的 request_id、版本、恢复代数和 payload 重试。版本或恢复代数冲突后重新读取并作出新的修改决定。

</Callout>
