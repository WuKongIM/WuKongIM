---
title: 启动单节点集群
description: 在 Linux 上安装 WuKongIM，并通过 systemd 启动单节点集群。
---

下面的命令都在 Linux 服务器执行。

## 1. 安装 WuKongIM

Ubuntu 或 Debian：

```bash
curl -fsSL https://packages.githubim.com/repo | sudo sh
sudo apt update
sudo apt install -y wukongim
```

Rocky、AlmaLinux 或 RHEL 9：

```bash
curl -fsSL https://packages.githubim.com/repo | sudo sh
sudo dnf -y --disablerepo='*' --enablerepo=wukongim-preview makecache --refresh
sudo dnf install -y wukongim
```

## 2. 初始化配置

```bash
sudo wukongim config init --config /etc/wukongim/wukongim.toml
sudo wukongim config validate --config /etc/wukongim/wukongim.toml
```

保存第一条命令显示的 Manager 管理员密码，它只显示一次。

## 3. 启动并检查

```bash
sudo systemctl enable --now wukongim
curl --fail http://127.0.0.1:5001/readyz
```

`/readyz` 成功表示单节点集群已经可以接收流量。失败时查看日志：

```bash
sudo journalctl -u wukongim -n 100 --no-pager
```

## 4. 从电脑打开页面

如果 Linux 是远程服务器，在电脑终端建立 SSH 转发并保持终端运行：

```bash
ssh -L 5001:127.0.0.1:5001 -L 5200:127.0.0.1:5200 -L 5301:127.0.0.1:5301 <用户名>@<服务器IP>
```

然后在电脑浏览器打开：

| 页面 | 地址 |
| --- | --- |
| Chat Demo | `http://127.0.0.1:5001/demo/` |
| Manager | `http://127.0.0.1:5301` |

Manager 用户名是 `admin`，密码是初始化时保存的密码。

停止或再次启动服务：

```bash
sudo systemctl stop wukongim
sudo systemctl start wukongim
```

数据保存在 `/var/lib/wukongim`。下一步：[发送第一条消息](/zh/guide/quick-start/first-message)。
