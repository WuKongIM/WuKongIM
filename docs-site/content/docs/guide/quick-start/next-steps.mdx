## 常见问题

### 单节点集群是不是独立模式？

不是。它是只有一个节点的集群，仍使用 Controller、Slot、Channel、路由和持久化路径。

### 可以把示例配置直接用于生产吗？

不可以。至少需要替换固定凭据，规划 TLS 和访问控制，把数据放在受管理的持久化存储上，并按真实负载验证容量、故障恢复和尾延迟。

### 为什么重启后还能看到数据？

示例配置把节点数据保存在 `./data/wukongim-single-node-data`。停止进程不会删除这个目录。

### 如何修改端口？

复制 `wukongim.toml.example` 后，修改本地 `wukongim.toml` 中的 API、Manager、Gateway 和集群监听地址，再重启节点。不要改动示例模板来保存本机差异。

### 为什么生产客户端不能调用 `/user/token`？

这是演示身份接口。生产 Token 必须由受信任的业务后端在完成真实身份和权限校验后签发或更新。

### 三节点环境在哪里？

仓库根目录的 `docker-compose.yml` 提供三节点开发环境。它会暴露开发凭据和 Benchmark 能力，同样不能作为生产模板。
