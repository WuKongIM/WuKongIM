## Linux 服务器

- CPU 架构：`amd64` / `x86_64`；
- 系统：Ubuntu 24.04、Debian 13、Rocky Linux 9、AlmaLinux 9 或 RHEL 9；
- 可以使用 `sudo`，并能访问 `packages.githubim.com`；
- 本机可以通过 SSH 登录服务器。

在服务器检查环境：

```bash
uname -m
. /etc/os-release && echo "$PRETTY_NAME"
curl --version
sudo -v
```

## 需要的端口

| 端口 | 用途 |
| --- | --- |
| `5001` | HTTP API、就绪检查和 Chat Demo |
| `5100` | 客户端 TCP |
| `5200` | 客户端 WebSocket |
| `5301` | Manager |
| `7001` | 节点内部通信 |

快速开始默认只从服务器本机访问这些端口，不需要开放到公网。远程浏览器通过 SSH 转发访问；只需确保 SSH 端口可用。

安装包会创建 `/etc/wukongim`、`/var/lib/wukongim` 和 `/var/log/wukongim`。准备完成后继续[启动单节点集群](/zh/guide/quick-start/single-node-cluster)。
