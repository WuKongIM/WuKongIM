这条路径面向第一次使用 WuKongIM 的读者。完成后，你会在一台 Linux 服务器上运行单节点集群，并通过 Manager 和 Chat Demo 验证消息收发。

<Callout type="warn" title="先用于学习和测试">
  当前 Linux 软件源是 Preview 通道。本指南适合功能验证，不是完整的生产部署方案。
</Callout>

## 操作顺序

1. [检查环境](/zh/guide/quick-start/prerequisites)：准备受支持的 Linux 服务器、sudo、curl 和 SSH。
2. [启动单节点集群](/zh/guide/quick-start/single-node-cluster)：安装软件包、初始化配置并启动 systemd 服务。
3. [发送第一条消息](/zh/guide/quick-start/first-message)：用两个测试 UID 验证双向消息。
4. [了解 Chat Demo](/zh/guide/quick-start/chat-demo)：了解演示功能与生产接入的区别。
5. [选择下一步](/zh/guide/quick-start/next-steps)：继续配置、SDK、API 或运维文档。

## 完成标准

- `http://127.0.0.1:5001/readyz` 返回成功；
- `http://127.0.0.1:5301` 能打开 Manager；
- `http://127.0.0.1:5001/demo/` 能连接两个测试用户；
- 两个测试用户可以互相发送和接收消息。

预计需要 5～10 分钟，不包含服务器和系统软件下载时间。
