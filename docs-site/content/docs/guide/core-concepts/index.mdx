刚接触 WuKongIM 时，不需要先理解节点、Raft 或数据分片。先记住下面五个业务概念，就能看懂大多数接入文档：

| 概念 | 它回答的问题 | 一句话理解 |
| --- | --- | --- |
| 消息（Message） | 传递什么？ | 用户发出的一份内容，例如文字、图片、通知或业务指令 |
| 频道（Channel） | 发到哪里？ | 消息的目标和接收范围，可以表示单聊、群聊或其他通信场景 |
| 用户（User） | 谁在通信？ | 由业务系统定义、用稳定 UID 标识的通信身份 |
| 设备（Device） | 从哪个端点通信？ | 用户使用的手机、浏览器、桌面端或其他客户端实例 |
| 会话（Conversation） | 用户如何找到最近的聊天？ | 某个用户视角下的频道入口，通常显示最近消息和未读数 |

## 五个概念如何配合

以 Alice 给 Bob 发消息为例：

```text
Alice（用户）在手机（设备）上发送一条消息
                     ↓
              消息进入单聊频道
                     ↓
      Bob 的在线设备实时接收，离线设备稍后同步
                     ↓
       Alice 和 Bob 各自在会话列表中看到这次聊天
```

如果换成群聊，变化的主要是频道：频道 ID 变成群 ID，接收范围变成群成员。用户、设备、消息和会话的基本关系不变。

## WuKongIM 与业务系统的分工

WuKongIM 是通信基础设施，不替代你的账号和业务系统。

| 你的业务系统负责 | WuKongIM 负责 |
| --- | --- |
| 注册登录、昵称头像、好友与群资料 | 客户端连接、消息路由和实时投递 |
| 群成员、角色权限、内容审核 | 频道内消息顺序、持久化和离线同步 |
| 业务 Token 签发、风控、移动推送 | 设备在线连接和面向 UID 的会话数据 |
