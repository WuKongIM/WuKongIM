<Callout type="warn" title="先建立受信边界">
  当前 Product HTTP 没有通用业务鉴权。教程里的 HTTP 管理请求只由受信业务后端或受保护的测试环境执行。
</Callout>

**分别核对：** 消息提交、对端接收、恢复与业务完成。未读更新、推送厂商受理或命令同步游标，都不能代替业务结果。
