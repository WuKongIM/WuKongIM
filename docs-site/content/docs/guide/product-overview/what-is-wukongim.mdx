title: WuKongIM 是什么
description: 了解频道式消息模型、系统职责，以及适合使用 WuKongIM 的场景。

WuKongIM 是一个基于频道模型的通用消息系统。发送者不直接选择存储节点或投递节点，而是把消息发布到一个频道；集群负责找到频道 Leader、完成持久化提交，并把已提交消息同步或投递给接收者。

## 频道模型

频道是消息路由和存储的核心单位。单聊、群聊和业务自定义流都可以映射为频道：

1. 客户端或业务服务使用用户身份连接或调用接口。
2. 消息携带频道 ID、频道类型、客户端消息编号和业务 Payload。
3. 集群把频道定位到负责的 Channel 运行时。
4. 消息按频道顺序提交到持久化日志。
5. 在线接收者得到实时投递，离线或重连设备通过同步补齐已提交消息。

## 系统边界

WuKongIM 负责可靠的通信基础能力，但业务语义仍由应用所有：

- WuKongIM 管理连接、消息日志、复制、在线路由、会话状态和投递。
- 业务服务管理账号、好友或群业务规则、Token 签发、内容语义与审核。
- 客户端 SDK 管理连接生命周期、本地状态、消息展示和交互。

快速开始中的 `/user/token` 是演示接口，用来缩短本地验证路径。生产环境应由受信任的业务后端封装身份与 Token 流程，不应把演示能力直接暴露给公网客户端。

## 适合的场景

- 即时通讯、群聊和实时社区
- 应用内通知、客服与坐席通信
- IoT 上报、服务端指令和音视频信令
- 直播互动、流式消息和 AI 消息工作流
- 需要自托管、水平扩展和明确消息提交边界的通信系统

## 需要额外评估的场景

如果需求只是离线批处理、通用事件总线或长期分析查询，应先确认消息队列、流处理或分析数据库是否更贴合问题。WuKongIM 的核心目标是面向用户、设备和频道的实时通信。
