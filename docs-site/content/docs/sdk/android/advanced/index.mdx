## 上线前注意

- `1.5.5` 默认使用原始 TCP，公开 API 没有认证 TLS 开关。请使用受控网络入口，或采用经过安全评审的传输方案。
- 保持 `setDebug(false)`，并检查 Release 日志不会输出 Token 或消息正文。
- Token 保存在普通应用偏好中，本地数据库也不能替代系统级凭据保护。敏感凭据使用 Android Keystore 支持的方案，明确备份和退出清理策略。
- 混淆规则由应用负责；用开启 R8 的 Release 包测试连接、消息和自定义正文。
- 在真机覆盖弱网、后台恢复、Token 失效、被踢、离线消息、账号切换和版本回滚。
