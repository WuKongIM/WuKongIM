| 主题 | `1.5.5` 公开面 | 接入方必须补齐 |
| --- | --- | --- |
| 初始化 | `WKIM.getInstance().init(context, uid, token)`；应用级 context | 受信后端签发 UID/Token；客户端不得持有 Product HTTP 管理凭据 |
| 路由与连接 | `addOnGetIpAndPortListener`、`connection()`、`disconnect(false/true)`、连接状态监听 | Gateway host/port、超时、重试代际隔离和失败验收 |
| 频道 | `WKChannelType.PERSONAL`、`WKChannelType.GROUP`；源码还声明客服、社区、话题常量 | 服务端频道模型、授权和每类频道的真实场景验证 |
| 文本消息 | `WKTextContent` | SENDACK 拒绝分支与 Bob 在线接收 |
| 媒体消息 | `WKImageContent`、`WKVoiceContent`、`WKVideoContent` | `addOnUploadAttachListener` 对接业务上传；权限、压缩、失败恢复与大文件验收 |
| 自定义消息 | 继承 `WKMessageContent`，实现编码/解码，并调用 `registerContentMsg` | 跨平台固定相同 content type 和兼容策略 |
| 发送 | `sendMessage(WKMsg)`、`send(WKMessageContent, WKChannel)`、`sendWithOptions` | 区分本地入库、SENDACK 与对端接收；使用 `clientMsgNO` / `clientSeq` 关联 |
| 接收与状态 | `addOnNewMsgListener`、`addOnSendMsgCallback`、`addOnSendMsgAckListener` | 使用稳定 key 注册和移除；跨异步边界复制应用自有不可变快照 |
| 最近会话 | `ConversationManager` 与 `addOnSyncConversationListener` | 实现可信同步源；空 `WKSyncChat` 只适合全新测试账号，不是生产离线恢复 |

| 提醒、CMD、机器人 | `ReminderManager`、`CMDManager`、`RobotManager` | 对应服务端数据源、签名/授权与产品场景验收 |

## 消息内容与发送选项

`WKIM.init` 会注册文本、图片、视频和语音正文。对应类型是 `WKTextContent`、`WKImageContent`、`WKVideoContent`、`WKVoiceContent`。自定义正文必须有无参构造、唯一 `type`，并实现 `encodeMsg()` / `decodeMsg()`；只在一个平台注册不能形成跨平台协议。

`WKSendOptions` 提供 `expire`、`topicID`、`flame`、`flameSecond`、`robotID`、`setting` 和 `header`。这些字段存在于源码不等于服务端和所有客户端组合已验收；每项都要与协议、服务端配置和其他客户端共同测试。

发送事件有三层：

1. `addOnSendMsgCallback` 通知本地入库；
2. `addOnSendMsgAckListener` 提供 SENDACK，只有 `WKSendMsgResult.send_success` 是成功；
3. Bob 侧 `addOnNewMsgListener` 才证明在线接收。

立即创建的 `WKMsg.messageID` / `messageSeq` 可能尚未由服务端赋值。关联待发送项应使用 `clientMsgNO`，本地序列使用正数 `clientSeq`。

## 平台与网络能力边界

- 精确源码通过 xSocket `NonBlockingConnection` 打开原始 TCP，没有公开 TLS socket、TLS 选项或 `startTLS`。WKProto Payload 加密不认证服务端，不能替代 TLS。
- CONNECT 使用设备标记 `0=APP`；`1=WEB`、`2=PC` 是协议常量。这个事实不证明多端登录、系统推送或后台保活。
- SDK 公开面没有形成 Firebase/Huawei 等推送服务的端到端配置与 receipt。推送、通知权限、后台限制和厂商通道必须由应用单独设计和验收。
- `setDebug(false)` 与 `setWriteLog(false)` 应在初始化前保持关闭，但部分 warning 仍可能输出；开启 debug 时 `WKReceivedMsg.toString()` 可包含解密后的 Payload。
- UID/Token 存在普通 `MODE_PRIVATE` `SharedPreferences`；SQLCipher 以 UID 为 password。它们都不是独立密钥管理证明。

## 生产采用前的最小验收

- 固定并核对 `com.github.WuKongIM:WuKongIMAndroidSDK:1.5.5`、revision 与 AAR SHA-256；
- 在实际 AGP/JDK/Kotlin/设备矩阵构建普通与 minified Release；
- 验证连接超时、认证失败、踢下线、断网、重连代际和 listener 清理；
- 验证 Alice 本地入库、终止 SENDACK、Bob 在线接收以及真实离线/会话同步；
- 验证媒体权限、上传、失败恢复、推送与后台策略；
- 关闭或修复原始 TCP、Payload 日志、Token 存储、UID 数据库 key 与同进程换号风险；
- 生成平台自己的构建/设备/运行证据，不能复用仅覆盖 JavaScript/Web 的 `compatibility.json`。
