</Callout>

<Callout type="info" title="iOS 教程不扩展这份兼容快照">

</Callout>

<Callout type="info" title="Android 教程也不扩展这份兼容快照">

</Callout>

## 目标与完成标准

开始接入前，确认你的服务端 revision、`wukongimjssdk`、Node.js 和浏览器与同一份兼容快照一致。完成后，你应能指出当前组合是“已验证”“未验证”还是“已发生漂移”，而不是根据 `latest` 猜测兼容性。

## 兼容快照

未提供 attestation 文件时，共享快照输出 `verified: false` 和 `verification.status: "missing"`。只有成功 receipt 中完整的源码、锁文件、场景、SDK、Node.js、Playwright 与 Chromium tuple 和当前构建精确一致时，才会输出 `verified: true`。下表只是目标值，不是证据；格式错误或发生漂移的 receipt 仍保持未验证。

| 组成 | 当前兼容目标 |
| --- | --- |
| WuKongIM 服务端 | 构建时注入的源码 revision；按完整集群语义运行 |
| JavaScript SDK | `wukongimjssdk@1.3.5`，精确锁定 |
| 黄金样例 | `docs-site/examples/javascript-web-quickstart/` |
| Node.js | Receipt 目标为 `22.12.0`；样例声明的最低版本为 `20.11` |
| 浏览器 | Receipt 目标为 `@playwright/test@1.62.1`，Chromium revision `1234` / `151.0.7922.34` |

静态站同时发布 `/compatibility.json`。页面、样例和 CI 必须读取同一份事实；源码 revision 由构建注入，文档正文不手写可能过期的 SHA。

```bash
curl --fail https://docs.githubim.com/compatibility.json
```

## 浏览器范围

| 引擎 | 状态 |
| --- | --- |
| Chromium `151.0.7922.34`（revision `1234`） | 唯一的阻断性 smoke 验证目标；当前构建是否已附证据以上方 `verified` 为准 |
| Firefox | 当前快照未验证 |
| WebKit / Safari | 当前快照未验证 |

“未验证”不等于“一定不可用”，但也不能写成受支持保证。不要把本页概括为“支持所有现代浏览器”。

## 前置条件

- 能读取当前构建的 `/compatibility.json`；
- 能检出清单记录的服务端 revision；
- 使用样例提交的 npm lockfile，而不是滚动依赖；
- 只把附带完整 smoke 证明的组合标为已验证。

## 如何使用快照

1. 从 `compatibility.json` 取得服务端 revision 和精确 SDK 版本。
2. 检出对应服务端源码，不使用漂移的 `main` 或 SDK `latest`。
3. 在黄金样例目录运行 `npm ci`，保留锁文件。
4. 先运行样例检查，再按[快速接入](/zh/sdk/javascript/quickstart)完成真实单节点集群 smoke 场景。
5. 任一组成升级后，重跑整个场景并由集成门禁生成新的精确 receipt；不要手工标记验证状态。

## 预期结果

相同快照应能重复完成连接、Alice 与 Bob 双向持久消息、Bob 断开、重连和离线同步。页面只承诺这个窄场景，不承诺完整 SDK API、后台运行、推送、自定义消息或所有浏览器。

## 失败诊断

- **SDK 版本不是 `1.3.5`**：删除手工升级结果并重新运行 `npm ci`。
- **服务端 revision 不同**：先在本页把组合视为未验证；不要因为能够 CONNECT 就推断全部行为兼容。
- **只有某个浏览器失败**：记录准确引擎和版本；Firefox、WebKit/Safari 的结果不能由 Chromium 测试外推。
- **快照文件与页面不同**：这是发布错误，应让兼容性校验失败，而不是人工选择其中一个。

## 安全与责任边界

兼容性验证不补齐生产鉴权。默认 v3 Beta Gateway 不会自动把已存 Token 用作 CONNECT 校验，产品 HTTP 也没有通用业务鉴权中间件。版本匹配不能替代业务身份、TLS、访问控制、容量或故障恢复验证。
