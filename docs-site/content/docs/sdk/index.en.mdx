WuKongIM provides two client SDK families. Choose by how much client-side state the SDK should manage, then open the matching guide.

<Cards>
  <Card title="WuKongIMSDK" description="Full SDKs for connections, messages, local chats, unread counts, and offline data." href="/en/sdk/wukongim" />
  <Card title="WuKongEasySDK" description="Lightweight SDKs with fewer APIs for online connections and messaging." href="/en/sdk/easy" />
</Cards>

## Which one should I use?

| Your requirement | Recommended |
| --- | --- |
| The SDK should maintain local messages and the chat list | WuKongIMSDK |
| You need unread counts, history, and offline recovery | WuKongIMSDK |
| You only need an online connection plus send and receive | WuKongEasySDK |
| You want the smallest possible integration surface | WuKongEasySDK |

For a complete chat product, start with [WuKongIMSDK](/en/sdk/wukongim). To add lightweight realtime communication to an existing product, start with [WuKongEasySDK](/en/sdk/easy).
