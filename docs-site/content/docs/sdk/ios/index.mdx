`WuKongIMSDK` 是悟空 IM 的完整 iOS SDK。它负责长连接、消息收发、本地消息库、会话列表和频道资料，适合需要自行构建聊天界面的应用。

本文档对应 `WuKongIMSDK 1.1.1`，示例统一使用 Objective-C。

## 开始前

你需要准备：

- 一个可访问的 WuKongIM 服务；
- 两个测试用户，例如 `alice` 和 `bob`；
- 由你的业务服务端返回的 `uid`、`token`、连接 `host` 和 `port`；
- 一个支持 CocoaPods 的 iOS 工程。

<Callout type="info" title="Token 从哪里来？">
  Token 应由你的业务服务端生成并返回给已登录用户。不要在 App 中保存悟空 IM 的管理密钥，也不要让 App 调用管理接口创建 Token。
</Callout>
