## 上线前注意

- `1.1.1` 的默认连接是原始 TCP，公开配置中没有认证 TLS 开关。请在受控网络入口使用，或升级到经过你们安全评审的传输方案。
- 设置 `options.isDebug = NO`，并检查 Release 日志不会输出 Token 或消息正文。
- 本地消息库按 UID 隔离，但 UID 不是加密密钥。结合 iOS 文件保护、备份策略和退出账号后的数据清理一起设计。
- 在真机上覆盖弱网、后台恢复、Token 失效、被踢、离线消息和版本回滚。
