## 消息能力与结果边界

`WKIM.setup` 会注册文本、名片、图片、语音和视频正文。`WKSendOptions` 包含 `MessageHeader`、`Setting`、`expire` 与 `topicID`；header 暴露 `redDot`、`noPersist` 和 `syncOnce`。字段存在不等于目标服务端或其他客户端已完成互操作验证。

发送至少有三层证据：

1. `addOnMsgInsertedListener` 表示持久消息已取得正数 `clientSeq`；
2. `addOnRefreshMsgListener` 中只有 `WKSendMsgResult.sendSuccess` 是终止成功；
3. Bob 的 `addOnNewMsgListener` 是当前在线连接收到消息的证据。

`sendMessage(...)` wrapper 没有等待内部 `sendWithOption(...)`。需要有界发送结果的代码应直接 `await sendWithOption(...)`，并继续等待 SENDACK；本地 Future 返回不能代替服务端接受。

## Provider 与 listener 所有权

- 连接、消息、会话、频道、成员、提醒和 CMD 的 keyed listener 都必须保存 key，并用**相同 key**移除；
- `addOnSyncConversationListener`、`addOnSyncChannelMsgListener`、`addOnGetChannelListener`、`addOnUploadAttachmentListener` 与 `addOnMsgInsertedListener` 是应用级单槽位或无 remove API 的回调，页面不得各自覆盖；
- provider 应由应用级 dispatcher 安装一次，设置超时，并把完成结果绑定到当前 activation；
- `connect()` 会先执行 `disconnect(false)`，因此首次序列包含合成的 `fail(null)`；只有应用 provider 完成后的 `syncCompleted` 才开放发送。

## 平台与生产阻断项

- [`WKConnectionManager`](https://github.com/WuKongIM/WuKongIMFlutterSDK/blob/de1024276523119e38305c49a3a873caae4d5c59/lib/manager/connect_manager.dart) 使用原始 `Socket.connect`，没有认证 TLS；WKProto Payload 加密不能替代 TLS。
- `Options.debug` 默认 `true`，接收日志可能包含解密后的 Payload；生产应设为 `false`，同时检查系统、崩溃与远程日志链。
- `sqflite` 数据库未声明加密；`SharedPreferences` 保存 UID 作用域设备 ID 与 migration version。
- 地址按 `addr.split(":")` 解析，只能使用一个 DNS/IPv4 `host:port`，不是 URI 或 IPv6 literal。
- 断开/登出不会清空 `_sendingMsgMap`；连接失败还会安排没有公开取消句柄的延迟重连。超时、kick、二次 `connecting`、不确定发送与换号都应要求**进程重启**。
- package 自身 analyze 有 93 项 warning/info，`test/wksdk_test.dart` 还会在 packet cut/decode 路径触发 `RangeError`；不能宣称完整测试已通过。

## 采用前最小验收

- 固定 `1.7.9`、archive SHA、匹配 revision 与 `pubspec.lock`；
- 在每个目标平台分别运行 analyze、Release build、签名/安装和真实设备消息环；
- 验证认证失败、踢下线、断网、重连、同步 provider 失败和 listener 清理；
- 分别记录 Alice 本地入库、终止 SENDACK、Bob 在线接收、历史/离线同步；
- 对媒体、通知、后台、存储加密、迁移、日志和账号切换做平台专项验收；
- 关闭原始 TCP、明文状态、日志、重连取消与 `_sendingMsgMap` 阻断，或记录经评审的风险接受。
