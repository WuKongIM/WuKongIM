本页把应用依赖固定到实际发布的 `wukongimfluttersdk 1.7.9`。不要把仓库 `master`、旧 `v1.0.0` tag 或 `^1.7.9` 当成同一个构建身份。

## 1. 确认工具链与目标平台

package 只声明 Dart：

```yaml
environment:
  sdk: ">=2.17.0 <4.0.0"
```

它没有声明精确 Flutter 最低版本。pub.dev 当前标注 Android、iOS、macOS；源码导入 `dart:io`、调用 `Socket.connect` 并依赖 sqflite，因此本教程不发布 Web、Windows 或 Linux 运行支持。

本站临时消费端使用 Flutter `3.41.4`、Dart `3.11.1`、macOS `15.1` arm64：`flutter analyze` 和 macOS Release build 通过。Android host 缺少 command-line tools；iOS 临时 target 没有 Development Team/provisioning profile；三端都没有本站 Alice/Bob 运行 receipt。

先记录自己的：

```bash
flutter --version
dart --version
flutter doctor -v
```

## 2. 固定 package，不使用范围

在应用的 `pubspec.yaml` 中写精确版本：

```yaml
dependencies:
  flutter:
    sdk: flutter
  wukongimfluttersdk: 1.7.9
```

然后解析依赖：

```bash
flutter pub get
```

不要写 `wukongimfluttersdk: ^1.7.9`、`any` 或 Git `master`。`1.7.9` 的 pub.dev archive 是：

```text
https://pub.dev/api/archives/wukongimfluttersdk-1.7.9.tar.gz
SHA-256 b6191a86cd1e4caacaa4652e95709310eb1493f159fee65e1dd53c2a3ff9e80a
```

归档中的 `lib`、`assets`、`pubspec.yaml`、`CHANGELOG.md` 与官方仓库 revision `de1024276523119e38305c49a3a873caae4d5c59` 一致。仓库没有 `1.7.9` tag，pub.dev uploader 不是 verified publisher；因此归档内容哈希和匹配 revision 都要保留。

## 3. 提交并强制 lockfile

应用项目必须提交 `pubspec.lock`。确认直接依赖条目：

```yaml
wukongimfluttersdk:
  dependency: "direct main"
  description:
    name: wukongimfluttersdk
    sha256: b6191a86cd1e4caacaa4652e95709310eb1493f159fee65e1dd53c2a3ff9e80a
    url: "https://pub.dev"
  source: hosted
  version: "1.7.9"
```

CI 和 Release 构建先执行：

```bash
flutter pub get --enforce-lockfile
flutter analyze
flutter build <你的目标平台> --release
```

`--enforce-lockfile` 会拒绝不再满足 `pubspec.yaml` 的解析或 hosted package 内容哈希漂移。不要在 Release job 中先运行 `flutter pub upgrade`。

## 4. 评审传递依赖

发布包的直接约束如下；实际解析版本以应用 lockfile 为准：

| 依赖 | 发布约束 | 用途/评审点 |
| --- | --- | --- |
| `path` | `^1.8.3` | 数据库路径 |
| `encrypt` | `^5.0.1` | WKProto Payload AES-CBC；不是 TLS |
| `cupertino_icons` | `^1.0.2` | Flutter UI 资源 |
| `x25519` | `^0.1.1` | 会话密钥协商 |
| `hex` | `^0.2.0` | 字节编码 |
| `crypto` | `^3.0.6` | MD5/摘要兼容实现 |
| `uuid` | `^4.3.3` | client message/device identity |
| `dio` | `^5.3.2` | package 声明；业务同步仍由应用实现 |
| `shared_preferences` | `^2.2.0` | 设备 ID 与迁移版本 |
| `sqflite` | `^2.4.1` | 本地消息、会话、频道等 |
| `connectivity_plus` | `^6.1.0` | 网络状态轮询 |

这些都是范围约束。一次通过的组合不会证明未来重新解析仍兼容；应用 lockfile、Flutter/Dart 和平台原生依赖必须作为一个 tuple 评审。

## 5. 配置平台网络能力

Android Release 的主 manifest 需要网络权限：

```xml
<uses-permission android:name="android.permission.INTERNET" />
```

macOS App Sandbox 的 Debug/Profile 和 Release entitlements 都要允许客户端网络：

```xml
<key>com.apple.security.network.client</key>
<true/>
```

iOS/macOS/Android 还要按产品部署方式处理局域网权限、后台限制和网络安全策略。这里的配置只让原始 TCP socket 有机会建立，不会自动提供 TLS、证书校验、后台保活或推送。

## 6. 配置身份、路由与日志

身份和路由来自受信业务后端。SDK 的 `addr` 被源码用 `split(":")` 解析，只接受一个 DNS/IPv4 `host:port`，不要传 `tcp://`、`https://` 或 IPv6 literal。

```dart
final options = Options.newDefault(
  uidFromBackend,
  tokenFromBackend,
  addr: 'im.example.internal:5100',
)
  ..debug = false
  ..deviceFlag = 0;

final initialized = await WKIM.shared.setup(options);
if (!initialized) throw StateError('WKIM setup failed');
```

`deviceFlag = 0` 对应 `0=APP`；`1=WEB`、`2=PC` 不适用于本移动/桌面 app 验收。`Options.debug` 默认是 `true`，必须在 setup 前关闭。debug 解码路径会输出带明文 **Payload** 的 `RecvPacket.toString()`；`ConnectPacket.toString()` 还包含 UID 和 Token，业务日志也不能打印它。

## 7. 理解本地数据

`setup` 会打开 `wk_<uid>.db` 普通 **sqflite** 数据库，并调用 `updateSendingMsgFail()` 把上次遗留的发送中记录标为失败；它不是发送恢复。SDK 没有提供数据库静态加密。**SharedPreferences** 还保存 UID 关联的设备 ID 与 SQL 迁移版本。

在采用前明确：

- 数据库和备份是否满足设备加密、企业管控与删除要求；
- Token 由应用保存在何处、何时撤销；
- 账号退出如何清除业务缓存；
- `disconnect(true)` 不清空 `_sendingMsgMap`，必须先取得终止 SENDACK，并把换号隔离到新进程。

## 8. 保留真实构建证据

建议保留：

```text
package version + archive SHA + source revision
pubspec.lock digest
Flutter + Dart + native toolchain
platform + build mode + device/OS
server revision
redacted Alice/Bob timestamps and clientMsgNO/clientSeq
```

包自身当前 `flutter analyze` 有 93 条 warning/info，`flutter test` 的 `cust data` 在 `ReadData.readString` 协议切包路径抛 `RangeError`。本站消费端的 macOS build 通过不能覆盖该失败，也不是 Android/iOS 或运行 receipt。

## 上线阻断

- `Socket.connect` 是原始 **TCP**，没有认证 TLS；
- 普通 sqflite、SharedPreferences 与 **Payload** 日志没有达到生产数据保护；
- `_sendingMsgMap`、不可取消重连 Future 与无 remove 的单例 provider 要求终止路径**进程重启**；
- parser 测试失败、离线/推送/后台/多设备尚无完整证据。
