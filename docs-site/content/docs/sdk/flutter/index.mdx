`wukongimfluttersdk` 是悟空 IM 的完整 Flutter SDK。它负责长连接、消息收发、sqflite 本地数据、会话列表和频道资料，适合需要自行构建聊天界面的 Flutter 应用。

本文档对应 `wukongimfluttersdk 1.7.9`，示例统一使用 Dart。该包依赖 `dart:io` 和 sqflite，不适用于 Flutter Web。

## 开始前

你需要准备：

- 一个可访问的 WuKongIM 服务；
- 两个测试用户，例如 `alice` 和 `bob`；
- 由业务服务端返回的 `uid`、`token` 和 `host:port`；
- 一个已完成 Android 或 iOS 原生配置的 Flutter 工程。

<Callout type="info" title="Token 从哪里来？">
  Token 应由你的业务服务端生成并返回给已登录用户。不要在 App 中保存悟空 IM 的管理密钥，也不要让 App 调用管理接口创建 Token。
</Callout>
