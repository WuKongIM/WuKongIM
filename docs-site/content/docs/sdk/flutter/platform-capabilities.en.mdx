## Messaging and result boundary

`WKIM.setup` registers text, card, image, voice, and video content. `WKSendOptions` contains `MessageHeader`, `Setting`, `expire`, and `topicID`; the header exposes `redDot`, `noPersist`, and `syncOnce`. Source fields do not prove target-server or cross-client interoperability.

A send has at least three evidence layers:

1. `addOnMsgInsertedListener` means a persistent message received a positive `clientSeq`;
2. only `WKSendMsgResult.sendSuccess` in `addOnRefreshMsgListener` is terminal success;
3. Bob's `addOnNewMsgListener` proves receipt on the current online connection.

The `sendMessage(...)` wrapper does not await its internal `sendWithOption(...)`. Code that needs a bounded result should call and `await sendWithOption(...)` directly, then continue waiting for SENDACK. A local Future return is not server acceptance.

## Provider and listener ownership

- Keyed connection, message, conversation, channel, member, reminder, and CMD listeners must retain their key and remove with the **same key**.
- `addOnSyncConversationListener`, `addOnSyncChannelMsgListener`, `addOnGetChannelListener`, `addOnUploadAttachmentListener`, and `addOnMsgInsertedListener` are application-level single slot callbacks or have no remove API; pages must not overwrite them independently.
- Install providers once in an application dispatcher, bound completion with a timeout, and fence it to the active activation.
- `connect()` first calls `disconnect(false)`, so the first sequence includes synthetic `fail(null)`. Enable send only at `syncCompleted` after the application provider completes.

## Platform and production blockers

- [`WKConnectionManager`](https://github.com/WuKongIM/WuKongIMFlutterSDK/blob/de1024276523119e38305c49a3a873caae4d5c59/lib/manager/connect_manager.dart) uses raw `Socket.connect` without authenticated TLS. WKProto Payload encryption does not replace TLS.
- `Options.debug` defaults to `true`, and receive logs may include decrypted Payload. Set it to `false` and inspect system, crash, and remote logging paths.
- The `sqflite` database declares no encryption. `SharedPreferences` holds the UID-scoped device identifier and migration version.
- Route parsing uses `addr.split(":")`; supply one DNS/IPv4 `host:port`, not a URI or IPv6 literal.
- Disconnect/logout does not clear `_sendingMsgMap`, and connection failure schedules delayed reconnect without a public cancellation handle. Timeout, kick, a second `connecting`, uncertain send, and identity change therefore require a **process restart**.
- The package's own analyze reports 93 warning/info findings, and `test/wksdk_test.dart` reaches a `RangeError` in packet cut/decode. Do not claim its complete test suite passes.

## Minimum adoption acceptance

- Pin `1.7.9`, the archive SHA, matching revision, and `pubspec.lock`.
- Run analyze, Release build, signing/installation, and a real-device message loop separately on every target.
- Exercise authentication failure, kick, network loss, reconnect, provider rejection, and listener cleanup.
- Record Alice local insertion, terminal SENDACK, Bob online receipt, and real history/offline synchronization separately.
- Validate media, notifications, background behavior, storage encryption, migration, logging, and account switching per platform.
- Fix raw TCP, plaintext state, logging, reconnect cancellation, and `_sendingMsgMap`, or record reviewed risk acceptance.
