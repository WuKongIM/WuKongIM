`wukongimjssdk` 是悟空 IM 的完整 JavaScript SDK。它管理 WebSocket、消息收发、内存中的会话列表和频道资料，适合浏览器、H5 以及经过单独适配验证的 JavaScript 运行时。

本文档对应 `wukongimjssdk 1.3.5`，示例统一使用 TypeScript。

## 开始前

你需要准备：

- 一个可从目标运行时访问的 WuKongIM WebSocket 地址；
- 两个测试用户，例如 `alice` 和 `bob`；
- 由业务服务端返回的 `uid`、`token` 和 `ws://` 或 `wss://` 地址；
- 一个使用 npm、pnpm 或 Yarn 的前端项目。

<Callout type="info" title="浏览器不能持有管理密钥">
  浏览器只应从你的业务服务端获取当前用户的短期 Token 和连接地址。创建用户、签发 Token 与访问控制都留在服务端。
</Callout>
