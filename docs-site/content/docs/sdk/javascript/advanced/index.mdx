## 上线前注意

- 生产网页使用 `wss://`，验证证书、反向代理 WebSocket Upgrade 和 CSP。
- `1.3.5` 的部分控制台输出不受 `config.debug` 控制，可能包含解码后的消息数据。发布前应采用经过评审的删除或脱敏方案，并检查最终 bundle。
- Token 只放内存或受控会话存储，避免 URL、分析事件、错误上报和浏览器日志。
- 覆盖断网重连、标签页休眠、Token 失效、被踢、离线去重、账号切换和版本回滚。
