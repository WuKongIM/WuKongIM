WuKongIMSDK is the full client SDK family with local messages, conversations, unread state, and offline recovery. APIs, dependencies, and runtime boundaries differ by platform, so start with the target platform and do not copy method names or compatibility conclusions across SDKs.

## Choose a platform

- [Android](/en/sdk/android): `WuKongIMAndroidSDK` `1.5.5`; source and JitPack AAR are aligned, with no site Android runtime receipt
- [iOS](/en/sdk/ios): `WuKongIMSDK` `1.1.1`; source and public headers are aligned, with no site iOS runtime receipt
- [JavaScript / Web](/en/sdk/javascript): `wukongimjssdk` `1.3.5`; includes a pinned Chromium scenario receipt
- [Flutter](/en/sdk/flutter): `wukongimfluttersdk` `1.7.9`; no site Flutter runtime receipt
- [HarmonyOS](/en/sdk/harmonyos): `@wukong/wkim` `1.1.7`; no site HarmonyOS runtime receipt
- [UniApp migration](/en/sdk/uniapp): the old SDK is deprecated, so only the JSSDK migration guide remains

If you are still comparing the full and lightweight SDK families, start with [Choose an SDK](/en/sdk/choose-sdk). See the [Common Guides](/en/sdk/common-guides) for cross-platform identity, messaging, conversation, and reconnect semantics.
