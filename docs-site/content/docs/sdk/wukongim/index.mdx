WuKongIMSDK 是带本地消息、会话、未读状态与离线恢复能力的完整客户端 SDK 系列。各平台的 API、依赖和运行边界不同，请从目标平台进入教程，不要跨平台复制方法名或兼容性结论。

## 选择平台

- [Android](/zh/sdk/android)：`WuKongIMAndroidSDK` `1.5.5`；源码与 JitPack AAR 已校对，没有本站 Android 运行 receipt
- [iOS](/zh/sdk/ios)：`WuKongIMSDK` `1.1.1`；源码与公开头文件已校对，没有本站 iOS 运行 receipt
- [JavaScript / Web](/zh/sdk/javascript)：`wukongimjssdk` `1.3.5`；具有固定 Chromium 场景 receipt
- [Flutter](/zh/sdk/flutter)：`wukongimfluttersdk` `1.7.9`；没有本站 Flutter 运行 receipt
- [HarmonyOS](/zh/sdk/harmonyos)：`@wukong/wkim` `1.1.7`；没有本站 HarmonyOS 运行 receipt
- [UniApp 迁移](/zh/sdk/uniapp)：旧 SDK 已弃用，仅保留迁移到 JSSDK 的指南

如果还在比较完整 SDK 与轻量 SDK，请先阅读[选择 SDK](/zh/sdk/choose-sdk)。跨平台的身份、消息、会话与重连语义见[公共指南](/zh/sdk/common-guides)。
