WuKongIMSDK 是完整版客户端 SDK。它不只负责网络连接，还会在客户端维护消息、会话、未读数和离线恢复所需的本地数据。

你通常会使用四类入口：

- **连接管理器**：连接、重连、断开和连接状态；
- **消息管理器**：发送、接收、查询和更新消息；
- **会话管理器**：聊天列表、最近消息和未读数；
- **频道管理器**：单聊或群聊的名称、头像和成员资料。

## 推荐阅读顺序

1. 先读[核心概念](/zh/sdk/wukongim/concepts)，花几分钟理解 UID、Token、频道、会话和 Provider。
2. 进入目标平台的“快速开始”，完成安装、连接和第一条在线文本消息。
3. 再按需要阅读连接、消息、会话、频道和高级功能。
4. 查方法名时使用平台的 API 参考；修改依赖版本前阅读[升级 SDK](/zh/sdk/wukongim/upgrade)。
