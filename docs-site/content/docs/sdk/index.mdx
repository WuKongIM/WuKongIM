SDK 文档当前发布一条窄而完整的 JavaScript/Web 路径：安装精确版本、通过 localhost BFF 建立开发身份、连接真实集群、双向发送持久消息，并验证断线后的离线恢复。

## 目标与完成标准

从本页出发，开发者应能选择已发布的兼容目标入口，而不是进入仍在规划的 SDK 菜单。当前构建是否附带完整验证证据，以兼容快照中的 receipt 状态为准。完成 JavaScript/Web Quickstart 后，应能区分持久提交、实时投递和离线同步。

## 兼容目标

Phase 12 固定 `wukongimjssdk@1.3.5`，并把服务端 revision、Node.js 与 Chromium 写入[兼容性快照](/zh/sdk/compatibility)。这不是所有平台或浏览器的支持矩阵。

## 前置条件

- 一个通过 `/readyz` 的 WuKongIM 单节点集群；
- Node.js `>=20.11` 与 npm，用于黄金样例；
- 理解浏览器只能访问 localhost BFF，不能直连 Product HTTP。

## 预期结果

黄金路径通过时，Alice 与 Bob 各自连接；双向消息分别显示 SENDACK 与 realtime 接收；Bob 断开期间提交的消息在重连后显示为 sync 恢复。

## 失败诊断

- **不确定从哪个 SDK 开始**：Phase 12 只验证 JavaScript/Web；其他平台不要从规划菜单推断支持。
- **版本不一致**：回到兼容快照并使用 lockfile，不要改用 `latest`。
- **示例能连接但安全评审失败**：这是开发路径，不具备生产 Token 校验和 HTTP 业务鉴权。

## 安全与责任边界

SDK 不拥有业务账号、授权或 Token 签发。默认 v3 Beta Gateway 不自动校验已存 Token，生产系统必须自行补齐身份边界、TLS、限流、审计和撤销。
