# Issue Agent E2E Domain

This domain contains temporary, Issue-linked regression scenarios generated by
the GitHub Issue Agent. All root `test/e2e/AGENTS.md` rules apply.

- Each child directory is named `issue_<number>`.
- Each child contains the reviewed generated `AGENTS.md` template and one
  primary `*_test.go` file.
- Tests must use only public, process-level behavior and `WK_E2E_BINARY`.
- A failing business assertion must print exactly one line:
  `WK_ISSUE_AGENT_ASSERTION_FAILED sha256:<64 lowercase hex>`.
- Setup, build, port, timeout, and infrastructure failures must not print the
  business-assertion marker.
- The assertion marker and core assertion are frozen after reproduction.
