three-node clusters with 256 Hash Slots.


pagination and its opaque continuation prove both Memberships exist before any SEND.

distinct remote UID Slot leaders and a remote source Slot leader from actual
public Slot inventory. Cover duplicate inputs, self-chat, multiple peers,
